# CoForge Lab · 共研实验室

用于验证人主导、AI Agent 执行的产研协作流程。

## 首个实验：需求收集小工具

计划使用 Vue 3，实现以下功能：

- 新增需求：标题必填，描述选填。
- 展示需求列表。
- 修改需求状态：待处理、进行中、已完成。
- 使用浏览器本地存储，刷新页面后保留数据。

第一版不包含后端服务、登录或多人权限。

## 验证流程

1. 调查仓库，整理实现方案、验收标准和测试计划。
2. 人工确认方案后，开始编码与测试。
3. 查看代码改动、实际测试结果和审查意见。
4. 人工完成最终验收。
